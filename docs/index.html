原理

数据本来就在你本机

没有云端，也没有账号体系。

1

读取本地数据

扫描 E听说 客户端的作业目录，不触碰账号。

2

识别作业结构

递归识别作业与套题目录，布局变化也不影响。

3

解析与展示

答案、精听、AI 对话，全部在本机呈现。

数据目录：Windows 为 %APPDATA%\ETS；Android 为应用私有数据目录。
Android 11+ 读不到别的应用目录是系统限制。应用提供 Root 或 Shizuku 提权提取，一键把数据拷到应用私有目录后即可使用。
AI 需自备接口，支持任意 OpenAI 兼容服务；不配置也不影响答案、精听与模拟考场。

FAQ

常见问题

需要登录 E听说 账号吗

不需要。应用只读取客户端已下载到本机的数据文件。

会上传作业数据吗

不会。解析全部在本地完成；仅在你主动使用 AI 功能时，内容才发往你自备的接口。

AI 必须配置吗

不必。答案、精听、模拟考场不依赖 AI。

安卓读不到数据怎么办

用应用内置的 Root 或 Shizuku 通道提取一次即可。

可以离线使用吗

答案、精听、模拟考场、悬浮窗全部离线可用。

软件收费吗

软件本身免费。AI 是否免费取决于你接入的服务商。
