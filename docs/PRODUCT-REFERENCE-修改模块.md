## 参考页结构（模块设置）

分组开关式设置页，每项一行：标题 + 说明副标题，右侧 toggle 或箭头进入二级页。

### 一、基础
| 项 | 类型 | 说明 |
| --- | --- | --- |
| 注入 `templet_common.html`（首次使用需注入） | 箭头页 | 首次使用前必须注入模板文件 |
| 显示答案 | 开关 | 开启后界面直接显示答案 |
| 自动填写答案 | 开关 | 开启后答案自动填入答题控件 |

### 二、考试模式
| 项 | 类型 | 说明 |

| 控制完成时间 | 开关 | — |
| 自定义完成时间（s） | 箭头页 | 配合上一项，单位秒 |
| 键盘工具 | 开关 | — |

修改指定成绩、修改完成时间（天/时/分/秒四框直接修改为）、HTTPS 证书说明。
