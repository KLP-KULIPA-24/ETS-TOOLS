# E听说助手 V0.8.1

**答案 · 成绩修改 · AI 解析，一次到位。** Windows 10/11 + Android 7.0 双端，本地优先、不联网上传作业数据。

> 本版主要是**下载渠道补齐**：四个入口（蓝奏云 / 银盘 / GitHub 解析 / GitHub 原版）全部接上真实链接，
> Shizuku 也是同样四个渠道；并修复了 Shizuku 加速下载前缀失效的问题（旧的 `gh.xmly.dev` 已连不上）。

## 本版变更

### 下载渠道

- 四个下载入口接上真实链接：**蓝奏云**（提取码 `ets`，点击自动复制）/ **银盘** / **GitHub 解析下载**（第三方节点加速）/
  **GitHub 原版下载**（官方 Releases 直链）。网页上点渠道卡是"选版本"（三个文件），
  点平台行的「下载」是"选渠道"（同一文件的四个入口）。
- **Shizuku（Android 提权工具）同样四个渠道**：蓝奏云（提取码 `ets`）/ 银盘 / 解析下载 / 官方直链——
  万一加速节点失效还有网盘兜底。App 设置页的 Shizuku 区新增「蓝奏云（ets）」「银盘」两个入口，
  蓝奏云点一下会自动把提取码复制到剪贴板。

### 修复

- **Shizuku 加速下载前缀失效**：旧的 `gh.xmly.dev` 已连不上，网页与 App 统一改用 `https://gh.b52m.cn/`。
- 手机端右上角导航的 GitHub 按钮在窄屏会被右边缘截断——手机端不再显示它（桌面端保留）。
