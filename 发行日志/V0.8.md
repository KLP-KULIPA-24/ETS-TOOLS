## 本版亮点

### 核心功能

- **答案**：五种题型专属排版（模仿朗读 / 角色扮演 / 故事复述 / 对话跟读 / 单词跟读），
  背题模式、逐句对照、题图点击全屏并双指缩放。
- **模仿朗读**：内嵌考试视频播放（双端原生控件：进度条 / 暂停 / 全屏 / 倍速）。
- **成绩修改**：本地拦截引擎接管作业提交，按规则改写**成绩**与**完成时间**，数据不出本机；
  提供 PAC（仅拦截 E听说 域名）/ 全流量两种接入模式。
- **AI 解析**：流式对话、全文翻译、AI 标题、未知题型识别；多提供商、多模态、思考档位，
  每个模型可单独配置失败重试与速率限制。

### 安卓数据读取（四种通道）

Shizuku（免 Root）/ Root（最高权限）/ 直读（零提权）/ SAF（系统授权）——任选其一即可把作业数据
提取到应用私有目录，应用内提供「选择工作授权模式」面板。

### 体验

- 主题：Material / 液态玻璃双风格，主题色可自定义（含粉色），跟随系统深浅色。
- 播放：全局迷你播放条（进度 / 暂停 / 关闭），返回上级自动停止，锁屏或退到后台继续播放。
- 跟读高亮、逐句精听（本地朗读 + 常驻进度条 + 右键/长按「朗读 / 问 AI / 复制」）。
- 媒体下载：图片 / 视频 / 录音支持系统分享与「保存到下载」，文件名自动命名为「套卷名-题型(Part)-语义名」。
- **检查更新**：启动时自动向官网查询版本号（设置 → 关于 可关闭），发现新版本提示「去下载」；
  关于卡的「检查更新」按钮可随时手动查。
- **开源仓库入口**：设置 → 关于、官网导航 / 首屏 / 页脚均提供 GitHub 仓库按钮。
- 思考档位：Agnes 出厂只启用「关 / 开」；其他模型默认低 / 中 / 高，档位可自定义。

## 本版主要修复

- AI 请求首 token 超时过长（20s × 5 次重试 → 最长 100s「加载中」）：超时缩短为 10s。
- 逐句播放的区间循环（播完自动重播 / 自动跳转）：现在播完即停。
- 液态玻璃在浅色主题下呈「实心白卡片」：重做透明度分层与三层折射。
- 视频控件进度条在 Windows 上仍为默认红色：补桌面端控件主题。
- 安卓悬浮窗点击无反应（入口函数未进编译产物 / 加载器未初始化 / 权限误报）。
- 模拟考场：题目内容与图片全程展示、录音交互化、回放后手动下一步。
- 套题识别：指挥目录 + 内容目录合并为一份套题，按 Part A/B/C 排序并标注。
- 下载文件名仍为 `content.mp3` 等原始名。
- 主题颜色预设里多出一枚重复色点。
- 浅色主题下背景右上柔和色斑边缘有可见弧线（看着像贴图）。
- 思考档位选不生效（选中未启用的档位现在会自动加入启用列表）。
- 出包脚本清理 CMake 缓存的路径笔误（避免构建静默产出旧包）。
