# STYLE — 标本 / 图录  (`catalogue-specimen`)

> 博物馆图录的一页：编号、标题、测量标注、中性底板。

| | |
|---|---|
| 底板 / 墨色 | 中性米灰板（#E9E7E2），一个强调色 |
| 字体 | 衬线标题 + 等宽编号，字号克制 |
| 音乐 | 60~80 BPM，弦乐或电钢长音 |
| 引擎 | core 的版式 + three（标本本体） |
| 排版空间 | 默认：W,H = 1280x720，交付 1920x1080 |

## 让它像这张牌的招式

- 编号 + 拉丁名式标题 + 尺寸标注
- 静物居中，缓慢推近
- 测量线、比例尺、切角标记
- 翻页式切场（整页替换）

## 注意

画面里的每个数字都要是代码算出来的真值，不许编。
